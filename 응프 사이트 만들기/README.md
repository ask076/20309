## 3. 반드시 지킬 규칙

### 파일 이름
- **영문 소문자와 하이픈만** 사용합니다. `poster-1.jpg` ✓ / `포스터 1.JPG` ✗
- 한글, 공백, 대문자를 쓰면 배포한 뒤 이미지가 깨집니다. 내 컴퓨터에서는 잘 보이는데 배포하면 안 보이는 사고의 1위 원인입니다.

### 경로
- `href="css/style.css"` 처럼 **슬래시로 시작하지 않게** 씁니다.
- `href="/css/style.css"` 는 배포하면 깨집니다.

### 색과 크기
- CSS에 숫자나 색 코드를 직접 쓰지 말고 반드시 `var(--이름)`을 쓰세요.
  ```css
  color: #1c3fd6;        /* ✗ */
  color: var(--brand);   /* ✓ */
  ```
- 값을 바꾸고 싶으면 `css/tokens.css`에서 바꿉니다.

### 건드리면 안 되는 것
- `tokens.css`의 **변수 이름** (값은 바꿔도 됩니다)
- `style.css`에서 `▸ 완성본`이라고 표시된 부분
- 폼의 `id` 이름들 (`name`, `tel`, `email`, `count`, `seat`, `agree`)
- `<script src="js/main.js">`의 위치 (`</body>` 바로 앞)

## 5. 이미지 넣는 법

처음에는 스타터에 들어 있는 임시 이미지 주소를 그대로 쓰세요.

```html
<img src="https://picsum.photos/seed/onstage1/600/800" alt="…">
```

`onstage1` 부분만 바꾸면 다른 사진이 나옵니다.

**6주차 전에는 실제 이미지로 바꾸는 것을 권합니다.** 다음 사이트에서 무료로 받을 수 있습니다.

- unsplash.com
- pexels.com
- pixabay.com

받은 파일은 `images/` 폴더에 넣고 이렇게 씁니다.

```html
<img src="images/poster-1.jpg" alt="밴드 공연 포스터">
```

⚠ **구글 이미지 검색으로 가져온 사진은 쓰면 안 됩니다.** 저작권 문제가 생깁니다.

⚠ `alt`는 "포스터"처럼 대충 쓰지 말고, 이미지를 볼 수 없는 사람이 무슨 사진인지 알 수 있게 씁니다. 6주차에 검사합니다.

## 6. 잘 안 될 때

### 화면이 아무 스타일 없이 나온다
`<link>` 경로나 파일 이름 오타입니다. F12 → Network 탭에서 빨간 줄(404)을 찾으세요.

### 분명히 썼는데 특정 규칙만 안 먹는다
우선순위 문제입니다. F12 → 해당 요소 클릭 → 오른쪽 Styles 패널에서 **취소선이 그어진 규칙**을 찾으세요.

### 요소가 상자 밖으로 삐져나온다
`* { box-sizing: border-box; }`를 지웠는지 확인하세요.

### 반응형이 안 먹는다
1. `<head>`에 `<meta name="viewport" …>`가 있는지
2. `@media` 블록이 CSS 파일 **맨 아래**에 있는지

### JS가 아무 반응이 없다
1. `<script>`가 `</body>` 바로 앞에 있는지
2. F12 → Console 탭에 빨간 오류가 있는지

### 폼을 제출하면 화면이 새로고침된다
`e.preventDefault();`를 안 썼습니다.

### 내 컴퓨터에선 되는데 배포하면 깨진다
파일 이름 대소문자, 또는 `/`로 시작하는 절대 경로입니다.
